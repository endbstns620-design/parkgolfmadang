# 파크골프마당 — 전국 파크골프장 정보 포털

전국 지자체 직영 파크골프장 정보, 대회 일정, 초보 가이드, 구장 리뷰, 동반자(동호회) 매칭, 광고를 제공하는
시니어(50~80대) 친화적 파크골프 정보 포털입니다.

---

## 🚀 로컬 실행

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정 (.env.example을 복사해서 .env로)
cp .env.example .env
# GEMINI_API_KEY 등 필요한 값을 채워주세요 (AI 챗봇/뉴스 생성 기능에 필요, 없어도 나머지는 정상 동작)

# 3. 개발 서버 실행 (http://localhost:3000)
npm run dev
```

## 🏗️ 프로덕션 빌드 및 실행

```bash
npm run build   # 프론트엔드(dist/) + 서버(dist/server.cjs) 빌드
npm start       # node dist/server.cjs 로 실행
```

## ⚠️ 배포 시 반드시 알아야 할 것 — "정적 호스팅"이 아닙니다

이 프로젝트는 **Node.js 서버가 계속 켜져 있어야 하는 구조**입니다. 화면(프론트엔드)뿐 아니라
아래 기능들이 전부 서버 API(`server.ts`)를 통해 동작하기 때문입니다.

- 구장 리뷰 (`/api/reviews`)
- 동반자 모집 게시글·댓글 (`/api/matches`)
- 광고/업체 정보 (`/api/ads`)
- 방문자 카운터, 날씨, AI 챗봇/뉴스 생성

**따라서 Netlify나 (지금 저장소에 남아있는) `vercel.json`의 정적 배포 설정으로는 이 기능들이 작동하지 않습니다.**
정적 배포 설정은 화면만 띄우고 서버 자체를 실행하지 않기 때문에, 리뷰를 남겨도 저장되지 않거나
동반자 모집글이 다른 방문자에게 보이지 않게 됩니다.

### 추천 배포처 (Node 서버를 계속 실행해주는 곳)
1. **Railway** (railway.app) — GitHub 연결 시 자동으로 `npm install` → `npm run build` → `npm start` 실행
2. **Render** (render.com) — Railway와 유사한 방식
3. **Fly.io** — 조금 더 기술적이지만 무료 티어 넉넉함

Vercel을 꼭 쓰고 싶다면, 정적 배포가 아니라 **Serverless Functions로 `server.ts`의 라우트를 이전**하는
추가 작업이 필요합니다 (지금 저장소엔 반영되어 있지 않습니다).

## 💾 데이터 저장 방식과 한계

리뷰·동반자모집·광고 데이터는 프로젝트 루트의 **`data/` 폴더에 JSON 파일로 저장**됩니다
(`server-lib/jsonStore.ts`). 별도 데이터베이스 설정 없이 바로 동작하는 대신, 아래 한계가 있습니다.

- **배포 플랫폼에 영구 디스크가 있어야 데이터가 유지됩니다.** Railway/Render의 기본 배포는 재배포 시
  디스크가 초기화될 수 있으니, 데이터를 계속 보존하려면 해당 서비스의 "Persistent Volume/Disk" 기능을
  연결해야 합니다.
- 트래픽이 많아지고 동시에 여러 명이 글을 쓰면 파일 쓰기 충돌 위험이 있습니다. 이용자가 늘어나면
  Supabase 같은 실제 데이터베이스로 옮기는 것을 권장합니다.
- 구장 목록 자체(600여 곳, `src/data/`)는 코드에 포함된 정적 데이터라 이 폴더와 무관하게 항상 유지됩니다.

## 🛠️ 주요 구성 및 기술 스택

- **프론트엔드**: React 19, TypeScript, Tailwind CSS v4, Motion(애니메이션), Lucide React
- **백엔드**: Express (server.ts), 파일 기반 저장소
- **AI 기능**: Google Gemini API (챗봇 상담, 뉴스 자동 생성)
- **콘텐츠 필터링**: 자체 스팸/부적절 콘텐츠 필터 (`src/utils/contentModeration.ts`) — 클라이언트·서버 양쪽에서 재사용
- **구장 데이터**: 대한파크골프협회·연맹 교차검증 데이터 기반 600여 곳 (`src/data/`)
